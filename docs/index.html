GETTING STARTED

三步开始实验

  1. 选择预设或修改参数。右侧结构示意和脚本会同步更新；掺杂浓度采用 cm⁻³，长度采用 μm。
  2. 下载 .cmd。将文件内容放进 Sentaurus Workbench 的 SDE 节点，运行后在 Visual 打开对应的 n…_msh.tdr。
  3. 比较结果。建议每组参数使用独立实验，避免覆盖输出。观察掺杂图与网格；若要电学曲线，还需运行 SDevice。

预览图只是帮助定位区域，不能代替 Sentaurus Visual 的数值结果。
